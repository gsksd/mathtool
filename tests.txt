Набор тестов для приложения "Решение уравнения" (Лабораторная работа №1)
============================================================================

Тест 1. Неверный формат ввода (буква вместо числа коэффициента A)
Входные данные:
  A = "abc"
Ожидаемый вывод:
  Решение уравнения вида: A*x^2 + B*x + C = 0
  Неверный ввод: значение не является целым числом.
  (приложение завершает работу)

Тест 2. Неверный формат ввода коэффициента B (вводится вещественное число)
Входные данные:
  A = 1
  B = "2.5"
Ожидаемый вывод:
  Решение уравнения вида: A*x^2 + B*x + C = 0
  Неверный ввод: значение не является целым числом.
  (приложение завершает работу)

Тест 3. Значение коэффициента вне допустимого диапазона (A = 50000)
Входные данные:
  A = 50000
Ожидаемый вывод:
  Решение уравнения вида: A*x^2 + B*x + C = 0
  Неверный ввод: значение по модулю превышает 10000.
  (приложение завершает работу)

Тест 4. Граничное (предельно допустимое) значение коэффициента
Входные данные:
  A = 10000
  B = 10000
  C = 10000
Ожидаемый вывод:
  Решение уравнения вида: A*x^2 + B*x + C = 0
  Уравнение квадратное: A*x^2 + B*x + C = 0
  Дискриминант: D = -300000000.000
  Действительных корней нет.

Тест 5. Квадратное уравнение, D > 0 (два корня)
Входные данные:
  A = 1
  B = -3
  C = 2
Ожидаемый вывод:
  Решение уравнения вида: A*x^2 + B*x + C = 0
  Уравнение квадратное: A*x^2 + B*x + C = 0
  Дискриминант: D = 1.000
  Корни уравнения: x1 = 2.000, x2 = 1.000

Тест 6. Квадратное уравнение, D = 0 (один корень)
Входные данные:
  A = 1
  B = -2
  C = 1
Ожидаемый вывод:
  Решение уравнения вида: A*x^2 + B*x + C = 0
  Уравнение квадратное: A*x^2 + B*x + C = 0
  Дискриминант: D = 0.000
  Корень уравнения: x = 1.000

Тест 7. Квадратное уравнение, D < 0 (нет действительных корней)
Входные данные:
  A = 1
  B = 2
  C = 5
Ожидаемый вывод:
  Решение уравнения вида: A*x^2 + B*x + C = 0
  Уравнение квадратное: A*x^2 + B*x + C = 0
  Дискриминант: D = -16.000
  Действительных корней нет.

Тест 8. Линейное уравнение, обычный случай (B != 0)
Входные данные:
  A = 0
  B = 2
  C = 3
Ожидаемый вывод:
  Решение уравнения вида: A*x^2 + B*x + C = 0
  Уравнение линейное: B*x + C = 0
  Корень уравнения: x = -1.500

Тест 9. Линейное уравнение, B = 0 и C = 0 (бесконечно много корней)
Входные данные:
  A = 0
  B = 0
  C = 0
Ожидаемый вывод:
  Решение уравнения вида: A*x^2 + B*x + C = 0
  Уравнение линейное: B*x + C = 0
  Корнем уравнения является любое действительное число.

Тест 10. Линейное уравнение, B = 0 и C != 0 (нет корней)
Входные данные:
  A = 0
  B = 0
  C = 5
Ожидаемый вывод:
  Решение уравнения вида: A*x^2 + B*x + C = 0
  Уравнение линейное: B*x + C = 0
  У уравнения нет корней.

Тест 11. Квадратное уравнение с вещественным (неокруглённым) корнем
Входные данные:
  A = 1
  B = -3
  C = 1
Ожидаемый вывод:
  Решение уравнения вида: A*x^2 + B*x + C = 0
  Уравнение квадратное: A*x^2 + B*x + C = 0
  Дискриминант: D = 5.000
  Корни уравнения: x1 = 2.618, x2 = 0.382
